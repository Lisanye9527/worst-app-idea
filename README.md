# The Worst App Idea Ever Pitched

A make.fun bounty entry: a deterministic Python program that pitches the
worst, most useless app imaginable in a single sentence of at most 240
characters.

Run it with:

    python3 main.py

It writes the pitch to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output/entry.txt`), after checking the text against the gate
(UTF-8, 1–240 characters, single line), and reads the file back to
verify what landed on disk.

Entry for the make.fun competition
[The Worst App Idea Ever Pitched](https://make.fun/bounty/u-plucky-sparrow-67-the-worst-app-idea-ever-pitched-a0396b23).
